# Proyecto Vue - Configurado para Firebase (Preconfiguración automática)

He revisado el contenido del ZIP original y añadí archivos de configuración y un scaffold de testing E2E. Este repositorio ya contiene Vue 3, Vuex, Vue Router, Vuetify y configuración de Firebase en `src/firebase.js`.

## Ejecutar en local
1. Instalar dependencias:
   ```bash
   npm install
   ```
2. Abrir Cypress:
   ```bash
   npm run cypress:open
   ```
3. Ejecutar tests en modo interactivo o headless:
   ```bash
   npm run cypress:run
   ```
