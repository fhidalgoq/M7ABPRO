# Catálogo de Productos - M7 AE1

Este proyecto es una implementación de ejemplo que satisface los requisitos de la actividad M7-AE1.

## Integrantes

Javiera Ampuero

## Ejecución

1. Node 16+ instalado
2. `npm install`
3. `npm run dev`

Abrir http://localhost:5173

## Incluye
- CatalogoProductos.vue: padre (lista, carrito, carga dinámica de detalle)
- TarjetaProducto.vue: hijo con props, eventos, slot y hooks de ciclo de vida
- DetalleProducto.vue: detalle dinámico
